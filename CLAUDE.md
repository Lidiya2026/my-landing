# Dogfooding: self-check before «готово»

После любой UI-правки, прежде чем сообщить «готово»:

1. Открыть URL приложения через Playwright MCP.
2. Прокликать изменённый элемент и ключевой сценарий рядом.
3. Проверить desktop и mobile (viewport 375px).
4. Если что-то сломалось — починить и повторить (максимум 2 итерации, затем остановиться и описать blocker).
